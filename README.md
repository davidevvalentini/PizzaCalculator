# PizzaCalculator

Calcolatore di impasti per pizza, in italiano e in inglese.
Pizza dough calculator, in Italian and English.

Ispirato al Calcolapizza de La Confraternita della Pizza, con un'interfaccia rifatta.

## Come funziona

All'apertura un wizard in 5 passi chiede tipo di pizza, quantità, tempo di lievitazione, temperatura di casa e pasta di riporto. Poi mostra il calcolatore con tutti i valori modificabili.

- Farina, acqua, sale, olio, pasta di riporto e lievito di birra fresco in grammi
- Lievito calcolato da ore totali, ore in frigo e temperatura ambiente
- Preset: Napoletana, Tonda romana (in teglia), Teglia romana, Pinsa
- Lingua IT / EN, scelta salvata nel browser
- Tema chiaro e scuro automatico

## Uso

È un singolo file senza dipendenze di build. Apri `index.html` nel browser, oppure pubblicalo con GitHub Pages.

## Nota sul lievito

Le formule del lievito sono una stima (modello a ore equivalenti a 20 °C, con il frigo a 0,3 volte la velocità). Non sono le stesse dell'originale. Correggi in base ai tuoi risultati.
